## Mục tiêu dự án

Thực hành Git workflow với GitHub Desktop:
- Áp dụng mô hình nhánh chuẩn (main, develop, feature/*)
- Sử dụng các tính năng quản lý commit nâng cao
- Làm việc nhóm thực sự với Pull Request và Review

## Cấu trúc Branch

```
main (production)
  ↑
develop (integration)
  ↑
feature/* (development)
```
